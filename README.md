# lan-screencast

Windows の画面と音を、同じ LAN にあるスマホ・タブレットのブラウザで見るためのツール。
映像と音は PC の Chrome/Edge から視聴端末へ WebRTC で直接送られ、`screencast.exe` は接続の仲介とページの配信だけをする。

## 使い方

1. `bun run build` で `dist/screencast.exe` を作る
2. `dist/screencast.exe` を Windows 側の好きな場所にコピーしてダブルクリックする
3. Windows ファイアウォールの確認が出たら「プライベート ネットワーク」を許可する
4. 自動で開く配信ページ（`http://localhost:47800/send`）で「画面・タブを選んで配信」を押す
5. 共有するものを選ぶ画面で、音声共有のスイッチをオンにする
6. スマホ・タブレットで配信ページの QR コードを読む

ポートは 47800 から順に空いている番号を使う。決めたいときは `screencast.exe 9000` のように数字を渡す。ブラウザを自動で開かないときは `--no-open`。

## 開発

- `bun run dev` … WSL 上でサーバーを起動（ブラウザは開かない）
- `bun test/e2e.ts` … ヘッドレス Chromium で送信・視聴・停止・再接続を確かめる

## 気をつけること

- 視聴ページは LAN 内の誰でも開ける。配信を始めた画面は、同じ Wi-Fi にいる人なら見られる
- 配信ページは `localhost` で開いたときだけ動く（画面の取り込みが安全な接続でしか許されないため）
- 取り込めるのは、共有したタブが画面に描かれているピクセル数まで。動画をPC側で全画面にすると、PCのモニターの解像度が上限になる（動画そのものが4Kでも、1920×1080 のモニターなら 1920×1080）。全画面にしないときは、ウィンドウの大きさとWindowsの表示スケールで決まる
- 音を送れるのは Chrome/Edge だけ。タブ共有ならそのタブの音、画面全体ならシステム全体の音が乗る
- 視聴ページの操作バー（画面をタップすると出る）の「設定」にある「−」「＋」で、音のタイミングを 10ms ずつ -300〜+500ms の範囲でずらせる。プラスは音を遅らせ、マイナスは映像を遅らせる（映像のほうは MediaStreamTrackProcessor がないブラウザでは使えない）。値は端末ごとにブラウザに残る
- PCで「タブの音を鳴らさない」は共有を始めた時点で決まる。配信中にチェックを変えたら共有し直す（Chrome が配信中の切り替えに対応していない。crbug.com/1381959）
- 「設定」の「全画面にしたとき横向きにする」がオンだと、全画面のときだけ横向きに固定する（Android の Chrome は端末の回転ロックより優先する）。全画面をやめると元に戻る
- 「PiP」は、ブラウザと端末がPiPに対応しているときだけ出る。音を早めている（映像を遅らせている）ときは、遅らせた映像がPiPに出る
- 取り込む解像度の上限は、初期値だと「つないでいる端末のうち一番大きい画面」に合わせる（最大 3840×2160）。大きい画面の端末が抜けたら、10秒待ってから残りの端末に合わせて下げる。上限を変えるたびに一瞬映像が途切れる。PCの負担を抑えたいときは「1080pまで」「720pまで」を選ぶ。Chrome の画面共有は解像度を固定できないので、実際のサイズは元のタブを一定の刻みで縮めた候補のうち、上限以下で最大のものになる

## 開発用モード

配信ページの一番下の「開発用モード」をオンにすると、次のものが出る。`screencast.exe --dev` で起動しても最初からオンになる。

- 配信ページ：取り込みの上限の決まり方（端末ごとの画面・縦横比・計算した枠・上限・取り込み中のサイズ）、端末ごとの送信側（圧縮時間・QP・ビットレート・制限の理由・往復の遅れなど）と受信側（デコード時間・受信バッファ・取りこぼし・停止・音の補い率・音の出力の遅れなど）の数字、出来事の記録
- 視聴ページ：左上に受信側の数字。「×」でその端末だけ隠せる。URL に `?dev=1` を付けると、配信ページの設定にかかわらず出る
- サーバー：`/api/debug`（このPCからだけ開ける）で、つないでいる端末・出来事・直近の受信状況をまとめて返す。開発用モードのときは出来事をターミナルにも出す

視聴側の「デコーダー」は、視聴ページがカメラ・マイク・画面の取り込みを使っていないので、Chrome がデコーダー名を返さず「—」になる（配信ページは画面を取り込んでいるので、エンコーダー名が出る）。
